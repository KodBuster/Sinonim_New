# Деплой «Синонима» на Amvera через GitHub

1. Создайте проект типа «Приложение» в Amvera. Во вкладке «Репозиторий» подключите GitHub, выберите `KodBuster/Sinonim_New`, ветку `main` и событие Push. Создайте токен GitHub с доступом только к этому репозиторию по инструкции Amvera и введите его в настройках интеграции. При ручной привязке укажите в GitHub URL и секрет вебхука, выданные в Amvera. [Инструкция Amvera](https://docs.amvera.ru/applications/git/webhooks.html)
2. На вкладке «Переменные» добавьте настройки ниже. Настройки приложения Amvera передаёт при запуске контейнера. После изменения переменных контейнер нужно перезапустить. [Переменные и секреты](https://docs.amvera.ru/applications/configuration/variables.html)
3. При первом развёртывании запустите синхронизацию из Amvera или отправьте подготовленный коммит в `main`. Конфигурация в `amvera.yaml` собирает приложение на Node.js 24 и запускает standalone-сервер на порту 80. Домены подключайте через HTTPS. Для текущих SQLite и счётчика заказов используйте один экземпляр приложения.

## Переменные

- `SITE_URL` = `https://synonym-jewelry.ru` для основного домена. Для отдельной тестовой установки укажите её HTTPS-адрес.
- `ADVANTSHOP_BASE_URL` = адрес текущей витрины AdvantShop. Сейчас каталог подключён к `http://shop.synonym-jewelry.ru`. Если у этой же витрины есть рабочий HTTPS-адрес, используйте его.
- `ADVANTSHOP_CATEGORY_MAP` = `rings:koltso,earrings:sergi,pendants:kole,bracelets:braslet`, если такие URL категорий остаются в AdvantShop.
- `ADVANTSHOP_ACCOUNT_BASE_URL` = рабочий HTTPS-адрес **той же** витрины AdvantShop. Нужен для входа, если основной URL использует HTTP. У текущего хоста HTTPS не подтвердился. Вход заработает после настройки доступного HTTPS-адреса и проверки входа тестовым покупателем.
- `ADVANTSHOP_REGISTER_URL` и `ADVANTSHOP_PASSWORD_RESET_URL` = полные HTTPS-ссылки на штатные страницы AdvantShop, если функции включены в магазине.
- `ADVANTSHOP_ORDERS_ENABLED` = `true`, только когда нужно отправлять заказы сайта в AdvantShop. По умолчанию отправка выключена. История в личном кабинете показывает заказы из AdvantShop.
- `YOOKASSA_SHOP_ID` — идентификатор магазина для онлайн-оплаты. Настраивается вместе с `YOOKASSA_SECRET_KEY`.
- `MAX_ADMIN_USER_IDS` или `MAX_ADMIN_CHAT_IDS` — получатели уведомлений о заказах в MAX. Несколько ID разделяются точкой с запятой.
- `FTP_HOST`, `FTP_USER`, `FTP_REMOTE_PATH` — если для остатков используется FTP. Для локального файла можно задать `STOCKS_CSV_PATH=/data/stocks.csv` и загрузить CSV в хранилище проекта.

## Секреты

- `ADVANTSHOP_CLIENT_API_KEY` — ключ из вкладки «API с авторизацией покупателя», нужен для каталога и входа.
- `ADVANTSHOP_SERVER_API_KEY` — ключ из вкладки «API», нужен для функций Server API, в том числе выгрузки заказов.
- `REVIEWS_ADMIN_TOKEN` — собственный случайный ключ от 32 символов для входа на `/admin/reviews`.
- `ADVANTSHOP_STORE_COOKIE` — только если витрина закрыта и изображения требуют сессионную cookie AdvantShop.
- `YOOKASSA_SECRET_KEY`, `MAX_BOT_TOKEN`, `FTP_PASSWORD` — для включённых интеграций.

Токен GitHub и секрет вебхука входят в настройки подключения репозитория. Их не нужно создавать как переменные приложения. Значения ключей и токенов не добавляйте в Git.

## Постоянные данные и проверка

Отзывы хранятся в `/data/reviews.sqlite`, следующий номер заказа — в `/data/order-counter.json`. Для переноса существующего приложения скопируйте данные в постоянное хранилище; если переносимого счётчика нет, заранее задайте `ORDER_NUMBER_START` как следующий свободный номер. [Хранилище Amvera](https://docs.amvera.ru/applications/storage.html)

После сборки проверьте главную, каталог, карточку товара и `/account`. Для проверки кабинета используйте тестового покупателя AdvantShop. Проверьте появление и отображение заказа перед включением онлайн-оплаты и уведомлений.
